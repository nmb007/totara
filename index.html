02

Integrations

Commerce, organisational data, payments, and virtual classrooms, connected as extensions of Totara.

Shopify and Odoo, through Workato

Shopify receives newly created Totara courses and publishes them to the client’s live store. Odoo provisions Totara users together with their departments and reporting lines, so onboarding does not depend on a manual copy of the org chart.

BigBlueButton

Adapted the BigBlueButton Moodle plugin for the current Totara version, so virtual classrooms run inside Totara where the Moodle plugin had no direct fit.

Google Meet on Seminars

A custom integration so a Totara Seminar event can host its meeting in Google Meet.

Stripe

A native Totara payment plugin, written because existing Moodle plugins did not fit. Learners purchase a course and are enrolled after a successful payment. Transaction history uses Report Builder, and learner messages use Totara Notifications.

03

Horizon

A Totara 20 child theme of Inspire. Each organisation gets its own colours, logo, and login artwork.

  • Full-screen login
  • Forgotten-password flow on the same branded card
  • Brand-coloured sidebar
  • Expand and collapse navigation, with a desktop default per tenant
  • Catalogue search in the top bar
  • Two-pane preferences, grouped into profile, learning, notifications, and the rest
  • Redesigned the performance drawer into a compact bar of labelled chips for page time, memory, and database, with GraphQL stats that expand when performance info is on
